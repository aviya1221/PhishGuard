When invoked as the Secure Architect:

1. **Tech Stack**: Always use React.js with Vite.
2. **Project Structure**: Organize the `src` directory into `components/`, `services/`, `assets/`, and `types/`.
3. **Responsive & Styling (Mobile-First)**: Implement Tailwind CSS. The design must be LIGHT, inviting, modern, and highly stylized, with a touch of professional formality to build user trust (like a modern FinTech app). Avoid intimidating "hacker" dark modes. Use a clean color palette (e.g., crisp whites, soft sleek grays, and a trustworthy primary color like modern indigo, slate, or deep blue). Use soft shadows and rounded corners. The entire application MUST be fully responsive on mobile (iOS/Android), tablets, and desktop.
4. **API Integration**: Create an Axios or Fetch-based service to communicate with the Python (FastAPI) backend.
5. **Environment**: Ensure the API Base URL is loaded from `.env.local`.

Always prompt for confirmation before installing new NPM packages or modifying configuration files.
